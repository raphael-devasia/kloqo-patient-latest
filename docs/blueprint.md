# **App Name**: MediQueue

## Core Features:

- Appointment Scheduling: Allows users to schedule new medical appointments by selecting a doctor, date, and time.
- Booking History: Displays a list of upcoming and past appointments with details such as date, time, doctor, and appointment type.
- Live Token Tracker: Shows the current queue status and estimated wait times, updating in real-time.
- Profile Management: Enables users to manage their profile information, including contact details and medical history.
- Smart Rescheduling Tool: Utilizes AI to provide smart suggestions for rescheduling appointments based on doctor's availability and patient's preferences. The LLM will use the user's existing schedule as a tool.

## Style Guidelines:

- Primary color: Light blue (#ADD8E6) to create a calm and trustworthy atmosphere.
- Background color: Clean white (#F5F5F5) to ensure clarity and readability.
- Accent color: Soft green (#90EE90) to highlight important actions and information.
- Body and headline font: 'PT Sans', a humanist sans-serif combining modern look and a little warmth.
- Use clear and simple icons for navigation and appointment types.
- Design a clean, intuitive layout with easy-to-navigate sections for scheduling, history, and profile.
- Incorporate subtle animations for loading and status updates to enhance user engagement.
